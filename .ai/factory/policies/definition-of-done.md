# Definition of Done

An issue is considered done when:

1. Acceptance criteria satisfied.
2. Relevant targeted tests pass.
3. Required full validation passes.
4. No unresolved reviewer findings.
5. Required documentation updated.
6. No accidental unrelated changes.
7. Required PR exists.
8. Human review completed where required.
