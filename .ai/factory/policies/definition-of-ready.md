# Definition of Ready

An issue must satisfy the following conditions to transition to `factory:ready`:

1. Clear objective.
2. Acceptance criteria.
3. Known non-goals where useful.
4. Relevant dependencies identified.
5. Risks identified.
6. Enough implementation context for an agent to begin.
7. No unresolved blocking questions.
8. Appropriate work type.
9. Appropriate risk level.
