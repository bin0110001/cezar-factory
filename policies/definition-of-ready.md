# Definition of Ready

An issue must satisfy the following conditions to transition to `factory:ready`:

1. Clear objective.
2. Acceptance criteria.
3. Known non-goals where useful.
4. Relevant dependencies identified.
5. Risks identified.
6. Enough implementation context for an agent to begin.
7. No unresolved blocking questions. Resolve routine ambiguity with a safe,
   reversible assumption and document it; only a major architectural decision
   that materially changes compatibility, ownership, or the system contract
   requires user input.
8. Appropriate work type.
9. Appropriate risk level.
